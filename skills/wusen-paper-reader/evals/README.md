# 场景测试与验证范围

用真实科研任务检查技能是否按场景工作，并将脚本可靠性与科学解读分别核验。[cases.json](cases.json) 保存五个请求与明确判据；测试源用DOI标识，不包含用户文库ID、PDF、批注或本机路径。

## 复现方式

1. 获取有权读取的论文主文和可用SI，保留来源与版本；已有解析Markdown时直接复用。
2. 使用干净会话加载SKILL.md，按请求只读相应场景和领域参考。
3. 按cases顺序运行，记录实际阅读页/章节、可见图表与缺失附件。
4. 将关键断言与原文核对，不能仅凭输出流畅或引用存在判合格。
5. 修改规则后在原任务与未参与修改的新论文上复测，防止针对少数案例过拟合。

## 实测推动的调整

- 回到曲线的初态、过渡态与终态，区别ΔG与ΔG‡；图文冲突并列记录。
- 区分实验直接测量、结合DFT参数的推算、作者选择的最大值及其余重复结果，不推断未定义的“±”类型。
- 区分旧凸包、更新凸包、生成样本与实验尝试集合；不从优选子集外推全部可合成性。
- “每克”不自动定义质量分母；须核对复合样品、载体或活性组分的定义。
